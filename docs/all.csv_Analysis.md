1. song_id : Song ID
2. difficulty: maps difficulties: {0:"PST",1:"PRS",2:"FTR",3:"BYD",4:"ETR"}
3. score : highest registered score
4. shiny_perfect_count : Shinies!
5. perfect_count : Pures, without the shinies
6. near_count : Far count
7. miss_count : Lost count
8. health : The gauge's remaining health on song end woaw
9. modifier : I have no idea
10. time_played : Unix timestamp of the last play (and highest in score)
11. best_clear_type : yk
12. clear_type : clear type (Too tired to actually map them :)
13. score_below_max : I don't know how do they count this, but it only works correctly on PMs I think
14. title : dict title in jap and eng
15. artist : yk
16. bg : some kind of hash
17. yearly_play_count : self explainatory
18. artwork : Artwork artist
19. multiplayer_room_code : Link play room code if that's where the play came from
